Demo: JSON Formatting & Repair

[Valid JSON]
  Input:  {"name": "Alice", "age": 30}
  Output: {"name": "Alice", "age": 30}

[Markdown fences]
  Input:  ```json
{"name": "Bob"}
```
  Output: {
  "name": "Bob"
}

[Single quotes]
  Input:  {'name': 'Charlie', 'score': 95}
  Output: {
  "name": "Charlie",
  "score": 95
}

[Trailing comma]
  Input:  {"key": "value",}
  Output: {
  "key": "value"
}

[Truly invalid]
  Input:  This is not JSON at all: ??? {]
  Output: {"error": "Không thể phân tích JSON", "raw": "This is not JSON at all: ??? {]"}

[Combined]
  Input:  ```json
{'items': [1, 2,],}
```
  Output: {
  "items": [
    1,
    2
  ]
}

[Preserve string]
  Input:  {"text": "don't delete ,}",}
  Output: {
  "text": "don't delete ,}"
}

✅ 7/7 JSON cases đạt.
